Eine nimmt sich selbst das Leben  
einen frisst die Krankheit auf  
eine stirbt durch fremde Hände  
doch sterben welche einfach so

Soll es so sein

Einer stirbt im Blech der Straße  
eine, eh sie atmen darf  
einen holt der Spruch des Richters  
doch sterben welche einfach so

Ist es das wert

Eine stirbt in bester Laune  
einer mitten in der Schicht  
eine geht und kommt nicht wieder  
doch sterben welche einfach so

Wer denkt sich das aus

Einer stirbt in fremden Kriegen  
eine, weil das Brot nicht reicht  
einer schläft sich aus dem Leben  
doch sterben welche einfach so

Eine stirbt im vollen Zimmer  
einer hinter seiner Tür  
einen sucht drei Wochen keiner  
doch sterben welche einfach so

Einfach so

Und welcher bin dann ich
